# Elevation — Design System Prompt
> Documentado: 25 de marzo de 2026 | Aprobado por Mauro Roldán

---

## FILOSOFÍA DE DISEÑO

Inspirado en el minimalismo japonés, filosofía Zen, estética Muji y experiencias digitales calmadas.

Este producto debe sentirse como:
- Un espacio seguro
- Un lugar para respirar
- Un ambiente emocional tranquilo

Evitar patrones corporativos SaaS.
Enfocarse en: Silencio · Espacio en blanco · Suavidad emocional · Interacciones lentas · Claridad

---

## SISTEMA DE COLORES

| Token | Valor | Uso |
|---|---|---|
| Primary (olive green) | `#6B7D5C` | CTAs principales |
| Secondary (soft green) | `#A8B5A2` | Elementos secundarios |
| Background (warm beige) | `#F4F1EC` | Fondo general |
| Surface (off-white) | `#FAF8F4` | Tarjetas, inputs |
| Text primary | `#2F2F2F` | Títulos, cuerpo |
| Text secondary | `#7A7A7A` | Labels, subtítulos |
| Accent | `#D6D2C4` | Divisores, bordes sutiles |

Sin negro puro. Sin contrastes duros.

---

## SISTEMA TIPOGRÁFICO

- **Títulos:** Playfair Display (serif elegante)
- **Cuerpo:** Inter o DM Sans
- Line height generoso
- Espaciado cómodo
- Ancho de lectura confortable
- Jerarquía calmada

---

## SISTEMA DE ESPACIADO

Escala suave: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`

Los layouts deben sentirse respirables.

---

## SISTEMA DE GRID

- **Desktop:** 12 columnas, max-width 1100px
- **Mobile:** Columna única
- Contenido centrado y equilibrado

---

## SISTEMA DE COMPONENTES

### Botones
- **Primary:** Fondo olive suave, bordes redondeados (8-12px), sin sombras fuertes, hover suave
- **Secondary:** Outline o relleno sutil, muy minimalista
- **Ghost:** Solo texto

### Inputs
- Fondo suave (#FAF8F4)
- Borde fino o sin borde
- Bordes redondeados
- Focus state con tono olive sutil

### Cards
- Contenedores muy suaves
- Sin sombras pesadas
- Usar espaciado en lugar de bordes
- Bordes redondeados

### Chat
- Burbujas mínimas, casi invisibles
- Los mensajes deben sentirse como entradas de diario
- **Usuario:** Fondo sutil
- **IA:** Texto plano con espaciado elegante

### Selector de emociones
- Íconos suaves
- Estados de selección redondeados
- Efectos hover calmados

### Navegación
- Muy mínima
- Top nav: Logo + Logout + Menú opcional
- Sin sidebars pesadas

### Divisores
- Líneas finas o solo espaciado

---

## MICROINTERACCIONES

- Transiciones muy sutiles
- Fade in lento
- Sin animaciones agresivas
- Efectos hover calmados

---

## ÍCONOS

- Líneas mínimas
- Trazo suave
- Sin íconos rellenos agresivos

---

## PANTALLAS A DISEÑAR

### 1. Landing Page
- Hero: *"This is a space for you."*
- Subtext: *"Talk, reflect and understand your emotions."*
- CTA: *"Start your reflection"*
- Layout muy minimalista

### 2. Login / Acceso
- Card centrada
- Inputs suaves
- Tono cálido

### 3. Onboarding emocional
- Una pregunta por pantalla
- Selección de emoción
- Layout muy espacioso

### 4. Diagnóstico emocional
- Flujo paso a paso calmado

### 5. Perfil emocional
- Display del estado emocional con indicadores suaves

### 6. Chat con IA Mentor
- Interfaz mínima
- Sin UI pesada
- Sensación de escribir en un diario
- Sugerencias suaves: respiración, reflexión, journaling

### 7. Herramientas de bienestar
- Grid layout
- Cada herramienta como un ritual

### 8. Dashboard emocional
- Gráficas mínimas
- Foco en claridad

### 9. Historial emocional
- Timeline
- Sensación de diario

### 10. Pantalla Premium
- UI de precios muy suave
- Sin venta agresiva

### 11. Panel de Administración (pendiente de definir)
- Gestión de prompts
- Flujo de aprobación
- Historial de versiones

### 12. Pantallas faltantes por definir
- Bloqueo por intentos fallidos
- Recuperación de contraseña
- Error / 404
- Primer acceso / Bienvenida

---

## PRINCIPIOS UX

- Eliminar todo lo innecesario
- Diseñar para comodidad emocional
- Evitar sobrecarga cognitiva

El usuario debe sentir:
- *"Puedo respirar aquí"*
- *"Me siento comprendido"*
- *"Quiero volver"*

2. ¿El backoffice mantiene el mismo estilo visual o tiene sistema propio?
3. ¿Prioridad mobile o desktop primero?
