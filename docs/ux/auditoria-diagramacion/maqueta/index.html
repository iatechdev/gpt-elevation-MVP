6 · Regla de capas de CSS

Hoy solo hay dos @layer (index.css:17 y cartografia.css:41); los 52 módulos restantes van sin capa y se pisan por orden de carga. Orden propuesto (de menor a mayor prioridad):

theme, base — Tailwind / reset
cg-tokens — tokens --cg-* y escalas
legacy — space.css, facilitation, therapist, accessAdmin… (importados con layer(legacy); se vacían pantalla a pantalla)
cg-frame — shell.css (cabecera, barra, cuerpo, pie: único dueño de ancho y márgenes)
cg-components — cartografia.css, pages.css
cg-screens — estilos de pantalla: PROHIBIDO width, max-width, margin-inline y padding-inline en la raíz de página; se usa .cg-page--read|form|card|room|panel
utilities — Tailwind

7 · Teclado y accesibilidad

Orden de Tab: «Saltar al contenido» → marca → navegación → idioma/tema → menú de usuario → contenido → pie. Foco único: 3 px de --cg-mark, desfase 3 px, en todas las pantallas (hoy hay 2 px #0369A1 en therapist.css:6 y 3 px de otros colores). La barra lateral con más ítems que la altura de la ventana se desplaza dentro de sí misma (overflow-y:auto; max-height: calc(100dvh − 2rem)), de modo que el último enlace siempre es alcanzable.
